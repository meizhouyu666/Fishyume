These plans record the delegated M1 and M2 implementation context. They were
moved from tool-specific `.claude/plans` metadata during the M6 core cleanup so
the repository no longer treats one local agent's state as project structure.

The plans are historical and may describe CC-Panes, legacy Backend names, RPC
methods, or product behavior that has since been retired. Use
[`../../fishyume-m6-core-contract-freeze.md`](../../fishyume-m6-core-contract-freeze.md)
and the root README as the current authority.
